fix(terminal): focus-trap was stealing keystrokes to the red close button

useFocusTrap re-ran on every render because callers passed a fresh
`excludeSelectors` array *and* an inline `onActivate` callback each render —
so on every keystroke the trap force-focused its first focusable element
(the red close button) and the visitor could only type one letter.

Fix: caller callbacks/arrays hoisted to module-level constants
(Style STABLE_EXCLUDE_SELECTORS + useCallback(activateSound) in Terminal),
hook now keys activation off the false→true edge of `active` (never mere
identity changes), and never steals focus from an element already inside
the trap.
